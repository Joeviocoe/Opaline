# Sources excluded from the armv7 / iOS 9 build.
#
# These files are LEFT IN THE TREE, UNMODIFIED.  Excluding them here rather
# than deleting or #if-ing them is what keeps merges from upstream clean:
# upstream can rewrite any of these freely and we never conflict, because we
# never touched them.  See "Staying mergeable with upstream" in the plan.
#
# build.sh fails if a path here no longer exists -- that is the early warning
# that upstream renamed or moved something and this list needs revisiting.
#
# POLICY: exclude only what cannot COMPILE for iOS 9.  Code that compiles but is
# useless at runtime (HLS-fMP4, PiP on an A5X, AV1, JS solving) stays in the
# build and is gated where it is *chosen* -- in the playback step registry and
# the format policy.  Excluding it instead would strand every reference to it,
# and each of those needs a hand-written stub that upstream will then diverge
# from.  Measured: excluding those files cost 31 dangling references, several of
# them @objc selectors that fail at runtime rather than at compile time.

# --- Network.framework (NWListener) is iOS 12.  This is the only genuine
# --- compile blocker in the tree.  The SABR *protocol* code is unaffected and
# --- stays compiled; only this sink is replaced by the resource loader.
